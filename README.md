Excel Sales Analysis Dashboard

Project Overview

This project analyzes sales data using Microsoft Excel to identify sales trends, compare customer segments, evaluate city performance, and analyze product profitability.

Tools & Skills

- Microsoft Excel
- Data Cleaning and Validation
- Pivot Tables
- Pivot Charts
- Interactive Slicers
- Sales KPIs and Dashboard Design

Dashboard Features

- Monthly Sales Trend: Tracks sales performance over time.
- Sales by Customer Segment: Compares Consumer, Small Business, and Corporate customers.
- Sales by City: Highlights differences in city sales performance.
- Profit by Product: Compares product profitability.
- Status Slicer: Filters the charts by order status.

Project Files

- "Excel_Sales_Analysis_Portfolio.xlsx" — Full Excel workbook with data, analysis, Pivot Tables, and interactive dashboard.
- "dashboard.png" — Dashboard preview image.
- "Excel_Sales_Dashboard.pdf" — Dashboard exported as a PDF.

Objective

The goal of this project is to turn raw sales data into meaningful insights through data analysis and interactive visualizations.
